# 🚀 WebSolution

Багатосторінковий, сучасний та повністю адаптивний веб-сайт, розроблений на чистому стеку веб-технологій (**HTML5, CSS3, JavaScript**) без використання сторонніх фреймворків.

---

## 📌 Структура сторінок (Pages)

- **Головна (`index.html`)**[cite: 1]: Головна сторінка з презентацією послуг та ключових переваг.
- **Про нас (`about.html`)**[cite: 1]: Інформація про компанію або розробника, місія та цінності.
- **Послуги (`services.html`)**[cite: 1]: Детальний огляд доступних веб-рішень та послуг.
- **Контакти (`contact.html`)**[cite: 1]: Форма зворотного зв'язку та контактні дані.

---

## 🛠 Технологічний стек (Tech Stack)

- **HTML5**: Семантична, валідна багатосторінкова розмітка.
- **CSS3**: Кастомні стилі (`style.css`), Flexbox та адаптивна верстка під різні пристрої[cite: 1].
- **JavaScript (Vanilla JS)** (`script.js`)[cite: 1]: Інтерактивність інтерфейсу, мобільне меню та обробка подій.
